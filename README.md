# Kundan DR - AI & Machine Learning Engineering Portfolio 🚀

![Portfolio Preview](/public/profile.jpg)

Welcome to the repository for my professional portfolio. This project is a highly interactive, 3D cinematic web application designed to showcase my skills, research, and professional experience in Artificial Intelligence, Machine Learning, and Full-Stack Engineering.

🌐 **Live Demo:** [https://kundandr-portfolio.vercel.app/](https://kundandr-portfolio.vercel.app/)

## ✨ Key Features
- **3D Cinematic Experience**: Powered by React Three Fiber and Three.js with smooth scroll-based camera transitions.
- **Modern UI/UX**: Premium "Aurora Midnight" glassmorphism aesthetic built with Tailwind CSS.
- **Dynamic Animations**: Fluid component entries and interactive micro-animations using Framer Motion.
- **Responsive Design**: Flawless execution across desktop, tablet, and mobile platforms.

## 🛠️ Technology Stack
- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Rendering**: [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) & [Drei](https://github.com/pmndrs/drei)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
